# Simple Interest Calculator

## Project Description

This project is a Bash-based Simple Interest Calculator. It calculates the simple interest using the principal amount, rate of interest, and time period provided by the user.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:

- Principal = Initial amount of money
- Rate = Rate of interest per year (%)
- Time = Time period in years

## Input

The calculator asks the user to enter:

1. Principal amount
2. Rate of interest
3. Time period

## Example

If:

- Principal = 1000
- Rate = 5%
- Time = 2 years

Then:

Simple Interest = (1000 × 5 × 2) / 100

Simple Interest = 100
